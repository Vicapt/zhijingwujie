# 大纲文件格式说明

## 放置位置
把 .txt 文件放在本目录（data/），然后在网页「教学大纲」模块中点击「导入外部大纲」选择文件即可。

## 格式规则

- `# 一级标题`   → 单元（大标题）
- `## 二级标题`  → 课文 / 课时
- `### 三级标题` → 知识点 / 小节（可选）

示例：
```
# 第一单元　阅读
## 1　草原
## 2　丁香结
### 丁香结　宗璞
# 第一单元　写作
## 热爱生活，热爱写作
```

---

## 排期标注（新）：@N课时 / @N周

「教学大纲」模块右侧的 **教学周历** 与 **教学进度提示** 两个栏目，需要知道每篇课文预计占
多少课时（以及各课在教学周时间轴上的先后位置）。因此在标题末尾追加一个排期标注即可：

| 写法 | 含义 |
|---|---|
| `## 1　草原 @3课时` | 这篇课文预计用 **3 课时**（1 课时 = 1 节课 40 分钟） |
| `## 3　任务一 @2周`     | 这个板块预计占 **2 个教学周**（会按「每周课时数」折算成课时） |

规则：

1. 标注写在标题**末尾**，前面用半角 `@`（全角 `＠` 也可以），数字与单位之间可有空格。
2. 标注只在 **二级标题（`##`）** 上最有效；写在一级标题（`#`）上表示「整个单元共 N 课时」，
   系统会按各课已有比例分摊下去（不足整除时余数补给第一课）。
3. 三级标题（`###`）上的标注，在其父级 `##` 没有课时数时，作为该课的课时数求和计算。
4. 标注在界面上**不会显示在标题里**（解析时自动剥离），但在大纲文本编辑器里可见，可手工修改。
5. 标注可以只写一部分：只标了部分课目的，其余课不参与排期，教学周历会提示「N 课未排期」。

### 判定进度所用的口径

- 学期可排课时总数 = （学期总周数 − 考试周数）× 每周课时数。
- 系统按 **教学周比例** 判断：算出自当前教学周起「应该推进到第几课」，再与实际已学习的
  课文比对，差值超过 1.5 课时/周判为「明显落后 / 进度超前」，0.5–1.5 判为「略微」，
  差值在 ±0.5 课时/周内判为「进度同步」。
- 若全册排期课时明显少于学期可排课时，会额外提示「排期未覆盖整学期」。

### 老师自编大纲怎么办

在「教学大纲」模块选中自己的大纲后，点击右侧 **AI 自动排课**，系统会把大纲（单元 / 课文 /
知识点）连同学期设置一起交给 DeepSeek，由它按「单元地位、课文篇幅与信息密度、能力训练
层次（新授:精练:迁移 ≈ 2:2:1）、知识点切分、单元衔接成本、单元小结、难易梯度、机动余量」
八条依据分配课时，并给出每条分配的**具体理由**，老师确认后才会写回大纲。
